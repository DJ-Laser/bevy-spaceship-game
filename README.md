# Bevy Spaceship Game

![Game Image](https://terra.hackclub-assets.com/b089d7cf-8c4f-4878-9162-d0ac826cafd7.png)

A 2D game about flying spaceships and fighting enemies.
Ships are fully customizable with many different parts, weapons, and systems to install.
Individual systems each have their own health bars and can break. target an enemy's engines to slow them down, or try targeting their inertial dampers so they lose control.

Currently, engines and power systems have been implemented, so you can fly around with a limited battery.
